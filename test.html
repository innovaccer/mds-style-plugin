Instructions

To test the MDS Style Inspector extension:

  1. Load the extension in Chrome (chrome://extensions/ → Load unpacked)
  2. Click the extension icon in the toolbar
  3. Click "Start Inspection"
  4. Elements with hardcoded CSS values should be highlighted with red borders
  5. Elements using design tokens (var(--token)) should NOT be highlighted
